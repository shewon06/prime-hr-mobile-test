Connect your secure database

This online application is published. To accept live employee data, configure Supabase Auth and the database first. No real HR records should be entered until setup is complete.

  1. Create your own Supabase project.
  2. Run the supplied schema.sql in Supabase SQL Editor.
  3. Set the project's URL and publishable key in config.js on GitHub.
  4. Create your login and approve the first admin via the README instructions.
